# Spacing checklist

- [ ] Every margin, padding and gap is a multiple of 4px.
- [ ] Values above 32px are reviewed by hand, not passed.
- [ ] Odd values such as 6px, 10px or 18px are reported, not read as on-scale.
- [ ] Matching gaps are equal across sibling cards and rows.
- [ ] Spacing uses the spacing tokens wherever a token exists.
