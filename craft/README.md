# Craft

Craft effects are small visual pieces an agent can build into a page, such as moving type or a soft reveal. Each one is its own skill: a brief of what makes the effect, the fixed steps, the values an agent may change, a React template and a check script that confirms the copy still follows the rules.

| Effect | What it does | Install |
|-|-|-|
| [Blur reveal](demo-effect) | A line of text whose words sharpen in from a soft blur, one after another. | `npx skills@latest add Nexvyn/designthink --skill demo-effect` |
