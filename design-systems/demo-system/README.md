# Demo system

Demo: replace this system with your own.

Quiet and monochrome, a starting point for your own system.

## Inside

- `SKILL.md` the rules an agent follows when it builds with this system.
- `tokens.css` colours for light and dark, a 4px spacing scale, four text sizes, a radius and an easing curve.
- `ui/button.tsx` a small button in two variants and two sizes.

## Install

```bash
npx skills@latest add Nexvyn/designthink --skill demo-system
```
