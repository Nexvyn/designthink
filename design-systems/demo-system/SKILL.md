# Demo system

Demo: replace this system with your own.

## Rules

1. Use only the values in `tokens.css`. No raw hex, rgb or oklch values in components.
2. Use one icon size per surface, 16px by default.
3. Set every margin, padding and gap on the 4px spacing scale, `--space-1` to `--space-8`.
4. Use only the four text sizes, `--text-xs` to `--text-lg`.
5. Use `--radius` for every corner and `--ease-out` for every transition.
6. Keep the palette monochrome. Do not add gradients or accent colours.
